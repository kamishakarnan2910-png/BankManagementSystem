Algorithm 

Start

Initialize ArrayList for accounts

Initialize Scanner for input

Display menu options

Read user choice

If choice = Create → Input details and add account

If choice = Deposit → Input account number and amount

Search ArrayList, update balance if found

If choice = Withdraw → Input account number and amount

Search ArrayList, deduct balance if valid

If choice = View Account → Input account number and display details

If choice = Delete Account → Input account number and remove account

If choice = View All Accounts → Display all accounts or show “No accounts”

If choice = Exit → End program

Stop
